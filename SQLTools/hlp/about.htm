SQLTools 3.0.2 by Lucas Matheus

Aleksey Kochetov Copyright © 1997-2026, Lucas Matheus 2026

SQLTools 3.0.2 is an enhanced and modernized version of SQLTools modified by Lucas Matheus, crafted specifically for high-productivity development of Oracle packages, procedures, functions, and advanced data visualization.

Source code, issues, and releases are publicly accessible at:
https://github.com/LucasAlves011/sqltools3

Key Enhancements

  • Value Panel ("Valor"): Collapsible side panel inspired by DBeaver with automatic BLOB/hex decoding and real-time color syntax highlighting for XML, JSON, and raw binary hex dumps.
  • PL/SQL Cursor Peek & Edit: Floating, pinnable popup displaying cursor definitions with live editing capability directly updating declarations.
  • Visual Scope Indicators: Visual scope lines connecting IF ... THEN and FOR statements directly to their block closures.
  • Productivity Features: Quick owner switcher buttons (DBAMV / MVINTEGRA), smooth mouse-wheel font zooming (Ctrl + Scroll), and stable scroll positioning when sorting DB Browser object lists.

System requirements

Developed and tested on Windows 10 and Windows 11 (64-bit). Requires a 64-bit Oracle Client (11g, 12c, 19c, or 21c).
