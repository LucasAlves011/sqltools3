Connect Settings

The dialog allows you to change settings for the Connect Dialog.

Master Password

User Connection information is stored in connections.xml. Some connection attributes are always encrypted. If user does not supply Master password then NONE is used as default for encryption. If Master password is not default then user will be asked to enter the password when SQLTools is starting.

Save passwords

Enable to keep passwords in connections.xml.

Enable On-Login PL/SQL block

If checked, and the next field is populated, the PL/SQL block is executed on connect for connections initiated from the Connect dialog, command line, or script.

Only a single PL/SQL block is supported. It must be written as a normal begin ... end; block without a trailing '/'.

The on-login block is stored encrypted, so you will be asked for the master password (if it is different from the default) when retrieving the text. You can use two predefined substitution variables: _USER and _CONNECT_IDENTIFIER (see example below). 

begin
  if '&_USER' = 'scott' and '&_CONNECT_IDENTIFIER' = 'soadb' then
    execute immediate 'alter session set current_schema = system';
    dbms_output.put_line('done');
  end if;
end;

You won't see dbms_output from the on-login block, but you can use it for debugging in the main window.
