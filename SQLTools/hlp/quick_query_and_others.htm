Quick Query / Quick Count / Find Object / Load DDL Script

These commands help you quickly obtain information about the object under the cursor. If the current statement is a DML operation, you can invoke a command on a table alias and get a result if the alias resolves to a table or (in some cases) a subquery.
You can also check Alias-Resolving Logic.
See examples at the bottom of this page.

Quick Query (F11)

Creates a simple query: SELECT * FROM (source), where source is either the table under the cursor or a table/subquery resolved from the alias under the cursor.

Quick Count (Ctrl+F11)

Creates a simple count query: SELECT COUNT(*) FROM (source), using the same alias-resolution rules as Quick Query.

Find Object (F12)

Treats the word under the cursor as an alias; otherwise assumes it is a table name and passes it to Object Viewer. This command was introduced as an alternative to the SQL*Plus DESC command.

Load DDL Script (Ctrl+F12)

Treats the word under the cursor as an alias; otherwise assumes it is a table name and passes it to the DDL Loader.

Example 1

The simplest case: no alias, cursor on the table. All commands in this group work. Additionally, you can select the whole statement and press F11 to count all records without modifying the SQL.
^ shows the cursor position 

SELECT * FROM emp^ WHERE rownum < 3;
Example 2

A query with a table alias. Quick Query and Quick Count work with aliases, but Find Object and Load DDL fail unless the cursor is placed on the actual table name. 

SELECT e2.^ FROM (SELECT empno, ename FROM emp WHERE rownum < 3) e2;
Example 3

Generally, nothing works with CTEs (WITH ... AS ...) except Autocomplete. 

WITH e AS (SELECT empno, ename FROM emp WHERE rownum < 3)
SELECT e2.^ FROM e e2;
